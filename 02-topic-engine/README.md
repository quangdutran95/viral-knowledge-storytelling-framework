# 02 — Topic Engine

Tạo chủ đề từ giao điểm: vấn đề thật × curiosity × knowledge value × emotional relevance × visualizability.

Ưu tiên các chủ đề có tension như: “điều tưởng tốt nhưng lại gây hại”, “vì sao càng cố càng thất bại”, “thứ bạn nghĩ là tính cách thực ra là một cơ chế tâm lý”.

Đầu ra: topic, core problem, target audience, angle, curiosity question, expected insight, viral score.
