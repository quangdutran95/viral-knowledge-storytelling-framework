# Viral Knowledge Storytelling Framework (VKSF)

Hệ thống sản xuất nội dung tri thức lan truyền dành cho TikTok, Facebook Reels và YouTube Shorts.

## Mục tiêu

Biến một ý tưởng kiến thức thành một hệ thống đầu ra hoàn chỉnh: chủ đề → góc khai thác → hook → cảm xúc → câu chuyện → kiến thức → insight → kịch bản → storyboard whiteboard → voice-over → title/caption/hashtag → phân tích hiệu suất.

## Triết lý cốt lõi

**Ngạc nhiên → Đồng cảm → Suy ngẫm.**

VKSF không coi viral là một công thức bảo đảm lượt xem. Framework thiết kế các điều kiện làm tăng khả năng người xem dừng lại, xem tiếp, hiểu, ghi nhớ, lưu và chia sẻ.

`Idea → Score → Angle → Hook → Emotion Map → Story → Knowledge → Insight → Script → Retention Check → Visual Script → Whiteboard Storyboard → Voiceover → Packaging → Publish → Analytics → Learning`

## Nguyên tắc chất lượng

- Hook phải tạo lý do để tiếp tục xem trong 3 giây đầu.
- Nội dung phải có giá trị hiểu biết thực tế, không chỉ tạo động lực chung chung.
- Câu chuyện phải tạo cảm giác “đây là mình”.
- Insight phải ngắn, rõ và có khả năng áp dụng.
- Kết thúc phải để lại một ý nghĩ đáng nhớ.
- Không hứa hẹn viral; dùng dữ liệu thực tế để cải tiến vòng sau.
