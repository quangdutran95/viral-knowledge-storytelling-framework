# VKSF v1.2 — Content Factory

## Release Goal

VKSF chuyển từ framework mô tả sang production system: một topic có thể được triển khai thành một production pack hoàn chỉnh.

## New Components

- `CONTENT-FACTORY.md` — operating blueprint.
- `prompts/content-factory.md` — master production prompt.
- `templates/production-pack.md` — output template.
- `templates/analytics-input.md` — feedback loop.

## Standard Command

Dùng prompt Content Factory với:

```text
TOPIC = chủ đề cần sản xuất
AUDIENCE = đối tượng mục tiêu
PLATFORM = TikTok / Reels / Shorts
DURATION = thời lượng
GOAL = mục tiêu video
```

## Expected Result

Hệ thống tạo 20 lớp output, từ topic diagnosis đến analytics schema, đồng thời tự sửa nếu Viral Score thấp hoặc Quality Gate chưa đạt.
