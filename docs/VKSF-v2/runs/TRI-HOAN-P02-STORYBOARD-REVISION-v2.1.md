# TRI HOAN — P02 STORYBOARD REVISION v2.1

## Source
- Idea: P02 — Bạn tưởng mình lười, nhưng có thể đang né một cảm giác khó chịu
- Format: Whiteboard Explainer
- Duration: 60s
- Revision: v2.1 — derive storyboard from Script → Narrative Beat Map → Cognitive Beat Map → Visual Beat Map → Scene Map.
- Strategy, Angle, Communication Concept, Title, Hook, Narrative, Retention, Script are preserved from the approved run.

## Beat Map
1. REFRAME — đừng gọi mình lười.
2. SELF-RECOGNITION — việc quan trọng nhưng lại cầm điện thoại.
3. CONTRADICTION — việc mình thích có thể làm hàng giờ.
4. QUESTION — vậy có thật là lười?
5. REVEAL — có thể đang né cảm giác.
6. MECHANISM — sợ dở, thất bại, bị đánh giá, quá tải.
7. RELIEF — né giúp nhẹ nhõm ngay.
8. LOOP — nhẹ nhõm củng cố việc né.
9. SELF-MIRROR — đổi câu hỏi.
10. ACTION — một bước đủ nhỏ.

## Style Lock
- 9:16 vertical, white background, black marker line art, Vietnamese adult male 30–40, consistent character.
- Sparse props, strong negative space, minimal on-screen text.
- Hand-drawn reveal; no dense illustration; one primary visual idea per scene.
