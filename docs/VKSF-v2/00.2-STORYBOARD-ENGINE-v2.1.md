# VKSF v2.1 — STORYBOARD ENGINE PATCH

This patch supersedes the fixed-scene assumptions in earlier storyboard contracts.

## Runtime rule

When Stage 17 receives a GREENLIGHT script:

```text
SCRIPT
 ↓
BEAT EXTRACTION
 ↓
COGNITIVE CHANGE DETECTION
 ↓
VISUAL BEAT DESIGN
 ↓
SCENE SPLIT / MERGE
 ↓
TIMING ALLOCATION
 ↓
PRODUCTION STORYBOARD
```

## Scene-count algorithm

```text
scene_count = number of required visual beats after SPLIT/MERGE
```

Duration is a constraint, not a scene-count generator.

For 60s Whiteboard, use 12–16 as default planning range, but allow exceptions when the beat map justifies them.

## SPLIT triggers

Create a new scene when any of these changes:

- viewer question;
- causal relationship;
- mechanism;
- emotional state;
- character action;
- object state;
- metaphor state;
- retention mechanism;
- viewer understanding;
- action step.

## MERGE triggers

Merge adjacent beats only when:

- same primary cognitive function;
- same visual composition;
- no new object/action is needed;
- no retention beat is lost;
- comprehension remains clear.

## Hard prohibition

The engine MUST NOT generate a storyboard by:

```text
60s / 9 scenes
60s / 10 scenes
60s / fixed N scenes
```

## Scene contract

Every generated scene must contain:

```text
SCENE ID
START / END / DURATION
NARRATIVE BEAT
PRIMARY FUNCTION
RETENTION FUNCTION
VOICEOVER SEGMENT
VISUAL ACTION
DRAWING SEQUENCE
PRIMARY ELEMENT
SECONDARY ELEMENT if needed
SIGNAL if needed
CHARACTER ACTION if needed
PROP if needed
TEXT ON SCREEN if needed
CAMERA / FRAMING
MOTION / TRANSITION
SFX if needed
EMOTION
GENERATION PROMPT
```

## Validation

Reject storyboard if:

- a major cognitive change has no visual change;
- one scene has multiple competing primary functions;
- visual is only decorative/textual;
- timing cannot map to voiceover;
- scene count appears chosen before beat analysis;
- strategy was changed during production.

## Backward compatibility

Old run files remain historical artifacts. They are not silently overwritten.

If an old storyboard fails this contract:

```text
OLD RUN → AUDIT → REVISION v2.1 → QUALITY RECHECK
```
