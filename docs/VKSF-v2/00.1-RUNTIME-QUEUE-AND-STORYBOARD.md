# 2. TOP 8 ≠ TOP 1

Runtime phải trả về cả hai:

### TOP 8 PORTFOLIO

Dùng để xây dựng **content backlog**.

### TOP 1 PRODUCTION TARGET

Dùng để chạy tiếp:

```text
ANGLE → CONCEPT → TITLE/HOOK → NARRATIVE → RETENTION → SCRIPT → STORYBOARD → VOICE → CAPTION → QUALITY
```

Không được hiểu:

```text
20 → Top 8 → bỏ 7 → làm 1
```

Mà phải hiểu:

```text
20
 ↓
Top 8
 ↓
┌────────────────────────────┐
│ P02 → Production #001     │
│ P01 → Queue #002          │
│ P06 → Queue #003          │
│ P20 → Queue #004          │
│ P13 → Queue #005          │
│ P16 → Queue #006          │
│ P03 → Queue #007          │
│ P10 → Queue #008          │
└────────────────────────────┘
```

# 4. QUEUE STATUS

Valid statuses:

```text
QUEUED
IN_PRODUCTION
PRODUCED
PUBLISHED
ANALYZING
LEARNED
REVISE
REJECTED
```

After Quality:

```text
GREENLIGHT → PRODUCED / READY_TO_PUBLISH
REFINE → REVISE
HOLD → QUEUED
REJECT → REJECTED
```

After publication and analytics:

```text
PUBLISHED
 ↓
ANALYZING
 ↓
LEARNED
 ↓
VKSF FEEDBACK LOOP
```

Learning can change future scoring, angle selection and portfolio balance, but must not silently rewrite an already published asset.

# 5. STORYBOARD IS A REAL OUTPUT

Stage 17 is not complete if it only says:

```text
Scene 1: nhân vật nhìn laptop
Scene 2: cầm điện thoại
```

It must create a **production-ready storyboard**.

### Mandatory storyboard fields

| Field | Required |
|---|---|
| Scene ID | YES |
| Start time | YES |
| End time | YES |
| Duration | YES |
| Voiceover | YES |
| Narrative beat | YES |
| Retention mechanism | YES |
| Visual action | YES |
| Drawing sequence | YES |
| Character action | YES when needed |
| Prop | YES when needed |
| On-screen text | YES when needed |
| Camera / framing | YES |
| Motion / transition | YES |
| Audio / SFX | YES when needed |
| Emotional direction | YES |
| Generation prompt | YES |

---

# 6. WHITEBOARD STORYBOARD RULE

Whiteboard storyboard must translate:

```text
SCRIPT
 ↓
COGNITIVE BEAT
 ↓
VISUAL METAPHOR
 ↓
DRAWING ACTION
 ↓
CAMERA / MOTION
```

Core rule:

> **Mỗi lần nhận thức của người xem thay đổi, hình ảnh cũng phải thay đổi có chủ đích.**

Không dùng visual chỉ để lấp thời gian.

---

# 7. STORYBOARD TIMING RULE

For a 60s short:

```text
8–12 scenes
```

Target scene duration:

```text
3–8 seconds
```

Một scene có thể ngắn hơn khi cần pattern interrupt.

Một scene có thể dài hơn nếu đang giải thích một cơ chế cần liền mạch.

# 9. STORYBOARD QUALITY GATE

Storyboard chỉ GREENLIGHT khi:

- [ ] Mỗi script beat có visual tương ứng.
- [ ] Mỗi retention mechanism có visual support.
- [ ] Không có scene chỉ để trang trí.
- [ ] Timing tổng khớp duration.
- [ ] Drawing action cụ thể đủ để animator thực hiện.
- [ ] On-screen text không lặp toàn bộ voiceover.
- [ ] Visual metaphor dễ hiểu ở kích thước màn hình nhỏ.
- [ ] Style lock nhất quán.
- [ ] Character consistency được giữ.
- [ ] Có prompt cụ thể cho từng scene nếu cần AI image generation.
