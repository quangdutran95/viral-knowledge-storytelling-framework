# 16 — Analytics

Theo dõi: views, 3-second retention, average watch time, completion rate, likes, comments, saves, shares, follows, share rate, save rate.

Đọc dữ liệu theo pattern, không theo một video đơn lẻ. Sau mỗi batch video, cập nhật: hook nào thắng, angle nào thắng, độ dài nào thắng, emotion nào thắng, ending nào tạo save/share.

Output cuối vòng: **Keep / Change / Kill / Test Next**.
